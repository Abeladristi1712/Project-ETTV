Window shading

Select a window and a shading layer.

Spacing is measured on the wall between blade attachment lines, not the clear gap between inclined tips. Blank spacing distributes blades evenly. First blade starts at the top (H) or left (V); the final interval ends at the window edge. Rectangular windows support arrays. Selecting a blade edits/deletes its entire array.

BCA Appendix B: R₁ = P / H, R₂ = P / W. Inclination 0–50°. Each interval is calculated separately; SC is area weighted.

Drawing guide & model assumptions
  1. Choose Wall, then Rectangle, Circle, or Polyline. Click to place points. Press Enter to close a polyline.
  2. Select the footprint and use Push / Pull or Apply height. Walls, roof and floor are created together.
  3. In Select / Move mode, click a wall. Choose Window / glazing and draw inside that wall. Its area is removed from the opaque wall.
  4. Select a window, choose a shading layer, enter a projection and click Add shade.
  5. Choose Assess materials to calculate ETTV. Return with Edit geometry to change the design.

Circle footprints use 48 planar segments; each segment maps to the nearest of eight orientations. Areas come from editor geometry, not Rhino. Roof and floor are excluded from façade ETTV. Stacked volumes may meet at roof/floor level. Side-touching or intersecting volumes are rejected. Boolean unions and arbitrary solid-face extrusion are not supported; Push / Pull changes a building footprint's vertical height. Deleting a wall, roof or floor deletes that building and its attached windows/shades; Undo restores it.

Rhino layer guide: what geometry and orientation do I need?

Use separate layers for the building elements below. The category must be the top-level layer name; optionally put the direction in a sublayer with the exact compass code.

Orientation: use one of N, NE, E, SE, S, SW, W, or NW as the final sublayer name, for example WINDOW::NE. If no direction sublayer is present, the exporter estimates it from the surface normal; review the mapped direction in Step 2. A direction written only in an object name is not read as a layer override.

Geometry and matching: model walls, glazing, and shades as visible surfaces, Breps, extrusions, or meshes. For one-to-one pairing, name a window L01_N_B01_WIN and its horizontal / vertical shades L01_N_B01_H / L01_N_B01_V. L01 records level and B01 records façade segment; use consistent names. Same-orientation, same-level continuous shades may also be matched by geometry. Check unmatched shades and area/direction warnings before trusting ETTV.

Area values depend on layer labels and must be verified as external conditioned envelope. Projection ratios and horizontal/vertical blade inclinations are measured from GLB geometry where shading can be paired to glazing. Workbook egg-crate tables C20–C23 have one angle axis (horizontal blade); vertical-fin inclination is shown and used for vertical-only SC lookups, but the egg-crate lookup cannot apply a second independent angle. Ratios below table limits are design-only estimates.

Source & assumptions

ETTV formula, material values and CF follow the supplied workbook. Corrected egg-crate headings assign C22 to NE/NW and C23 to SE/SW. Tables C20–C23 provide 0–40° horizontal-blade tilt interpolation. Horizontal and vertical shading angles are measured from geometry where possible; the egg-crate workbook table has no separate vertical-fin angle axis. For SC table ratios below minimum, computed values are estimates, not compliant outputs.

Combined shading & scenarios

Both H and V shades are detected. Perpendicular, continuous egg-crate geometry can use workbook Tables C20–C23. Values within the table are interpolated along both projection ratios and the horizontal-blade angle. A separately measured vertical-fin angle is shown, but cannot be applied to the egg-crate lookup without a second workbook angle axis. R1 or R2 below 0.2 are design estimates only using a linear extension toward single-device SC and are NOT compliance figures. Select H-only or V-only for comparison scenarios. Manual inputs are available per façade. A mixture of PRs is calculated panel-by-panel with SC area weighting, never by averaging PRs.

MATERIAL & SHADING SEARCH

Find combinations for ETTV ≤ 45 W/m²

Tests the website's wall/glazing material presets with no shading and shading measured from this model.

Search scope & assumptions

Recommendations assume the same selected wall and glazing materials across all façade orientations. Shading choices use only this model's measured H+V, H-only or V-only geometry, plus a no-shading comparison; the search does not invent new shading dimensions or PR values. Add proposed shades to the model and re-import to test them. The workbook uses Glass SC, not SHGC; no SHGC conversion is applied. Only tabulated, non-estimated shading results are listed. Review material availability, cost, constructability and regulatory requirements separately.
